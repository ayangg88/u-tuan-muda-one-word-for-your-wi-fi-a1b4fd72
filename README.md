One word for your Wi-Fi: **Ghosting**.

Home Wi-Fi as it is actually lived — there one moment, gone the next,
mid-call, mid-game, mid-sentence, no explanation, no goodbye. The word
is the network name.

## Entry

`main.py` writes the single word to `/output/entry.txt`:

```
Ghosting
```

8 characters, one word, no trailing newline.
